🎙️ Customer Service Voice Agent

Connect and start speaking to interact with the agent

Status: Disconnected
Enter WebSocket server URL (e.g., ws://your-server:8000)
System Click "Connect" to start. Your browser will ask for microphone permission.
💡 Tips:
  • Make sure your server is running: uv run uvicorn server:app --host 0.0.0.0 --port 8000
  • Enter the server URL (e.g., ws://localhost:8000 or ws://192.168.10.248:8000)
  • Server URL can only be changed when disconnected
  • Allow microphone access when prompted
  • Speak naturally - the agent will respond with voice
  • Use the Mute button to control when you're transmitting audio
  • Check browser console (F12) for detailed logs
